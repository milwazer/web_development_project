# Органайзер — курсовой проект

Веб-приложение для учёта личных задач (тема № 11 «Органайзер»).
Пользователь ведёт свои задачи с категориями, приоритетами, дедлайнами и статусами,
фильтрует список и не забывает о просроченных делах.

## Возможности

- регистрация и авторизация (пароли хранятся в виде хешей);
- роли: гость, пользователь, администратор;
- задачи: создание, редактирование, удаление, смена статуса;
- категории задач у каждого пользователя свои;
- поиск по названию, фильтры (категория, статус, просроченные), пагинация;
- панель администратора: список пользователей, блокировка, удаление;
- защита: SQL-запросы с параметрами, CSRF-токены в формах, проверка прав на сервере.

## Технологии

| Слой | Средство |
|------|----------|
| Сервер | Python 3 + Flask |
| Шаблоны | Jinja2 (входит во Flask) |
| База данных | PostgreSQL |
| Драйвер БД | psycopg2 |
| Интерфейс | HTML + Bootstrap 5 (CDN) |
| Хеширование паролей | werkzeug (входит во Flask) |

## Запуск с нуля

1. **Python 3.10+** — установить с [python.org](https://www.python.org/downloads/),
   при установке отметить галочку *Add Python to PATH*.

2. **PostgreSQL** — установить с [postgresql.org](https://www.postgresql.org/download/windows/)
   (установщик EDB). Запомнить пароль пользователя `postgres`, заданный при установке.

3. **Скачать проект:**
   ```bash
   git clone https://github.com/milwazer/web_development_project.git
   cd web_development_project
   ```

4. **Установить зависимости:**
   ```bash
   pip install -r requirements.txt
   ```

5. **Создать базу данных.** Открыть *SQL Shell (psql)* из меню Пуск (или pgAdmin →
   Query Tool) и выполнить:
   ```sql
   CREATE DATABASE organizer;
   ```

6. **Применить скрипты** (из папки проекта, пароль postgres спросит):
   ```bash
   psql -U postgres -d organizer -f database.sql
   psql -U postgres -d organizer -f seed.sql
   ```

7. **Указать пароль от PostgreSQL** (один раз, пароль не попадает в код):
   ```bash
   setx DB_PASSWORD "ваш_пароль"
   ```
   После команды открыть **новое** окно консоли. Альтернатива — поменять значение
   по умолчанию в `config.py`.

8. **Запустить приложение:**
   ```bash
   python app.py
   ```

9. Открыть в браузере: **http://127.0.0.1:5000**

## Переменные окружения

Все настройки `config.py` можно переопределить переменными окружения
(значения по умолчанию — в скобках):

| Переменная | Назначение | По умолчанию |
|------------|------------|--------------|
| `DB_HOST` | адрес сервера БД | `localhost` |
| `DB_PORT` | порт PostgreSQL | `5432` |
| `DB_NAME` | имя базы | `organizer` |
| `DB_USER` | пользователь БД | `postgres` |
| `DB_PASSWORD` | пароль пользователя БД | `postgres` |
| `SECRET_KEY` | ключ подписи сессий | служебное значение |

## Запуск тестов

Из корня проекта (PostgreSQL должен работать):

```bash
python -m unittest discover tests -v
```

Тесты используют ту же базу `organizer`, созданных тестовых пользователей
удаляют за собой.

## Структура проекта

```
app.py          маршруты и логика приложения (Flask)
config.py       настройки подключения к БД и секретный ключ
db.py           подключение к PostgreSQL и выполнение запросов
database.sql    создание таблиц базы данных
seed.sql        тестовые данные
templates/      HTML-шаблоны страниц (Jinja2)
static/css/     стили
tests/          модульные тесты (unittest)
docs/           техническое задание и ER-диаграмма
```

## Частые проблемы

- **«password authentication failed»** при запуске скриптов или приложения —
  не задан `DB_PASSWORD` (шаг 7) или пароль не совпадает с паролем PostgreSQL.
- **«database organizer does not exist»** — пропущен шаг 5.
- **Порт 5000 занят** — запустить на другом порту:
  `python app.py` → правка в конце `app.py`: `app.run(debug=True, port=5001)`.
